# PWM
## Программный ШИМ (на базе TIM_6)
Период прерываний TIM_6: 10 мкс. Для реализации шага скважности 1% максимальная частота сигнала не может превышать 1000 Гц.

## Генерация PWM
| Тип | Диапазон частот, Гц|
|-|-|
|Программная | от 0 до 1000 
|Аппаратная	| от 0 до TIM_CLK / 2

## Измерение частоты
|Тип | Диапазон, Гц	| Примечание|
|-|-|-|
|Программное| 1 … 1 000 000 | Используется TIM_7 + EXTI|
|Аппаратное	| 16 … 200 000 |	Разрешение 1 мкс|


Программное измерение (TIM_7 + EXTI). Таймер TIM_7 генерирует прерывание каждую секунду. Переменная software_counter_ic инкрементируется при каждом фронте сигнала (вход EXTI). Частота определяется как количество фронтов за 1 секунду.
