Отладочная плата: WeaAct_STM32F446RE

Алгоритм настройки PWM: ./Doc
Для генерации программного ШИМ используется TIM_6 с периодом прерываний 10 мкс => для реализации шага скважности 1% максимальная частота сигнала не может быть больше 1000 Гц
Генерация PWM :
    - Программная от 0 до 1000 Гц
    - Аппаратная от 0 до TIM_CLK / 2

Измерение частоты:
    - Программная от 1 до 1_000_000 Гц
    - Аппаратная от 16 до 200_000 ГЦ
Разрешение аппаратного измерения частоты 1 мкс
Для измерения частоты программно используется TIM_7, который прерывается каждую й сек, и переменная software_counter_ic, которая инрементируется при каждом фронте сигнала (EXTI)

Логика настройки реализована в директории ./Software/App
На данный момент реализован приём команд по USB и отправка ответов по UART
Для отпраки сообщений по UART используется очередь tx_queue (application.cpp). Каждые 5 мс TIM_3 прерывается и происходит проверка на наличие сообщений в очереди, если есть сообщение, то начать отправку с использованием DMA
